# Checklist ผล UAT CareFlow ก่อน Pilot

ใช้คู่กับ [guide-th.md](guide-th.md) เท่านั้น ชุดนี้เป็น local synthetic pre-pilot UAT: ไม่มีข้อมูลจริง, ไม่มีการ deploy, ไม่มี backup/restore และไม่มีการเชื่อมต่อภายนอก

## ข้อมูลการรัน

สำหรับแต่ละแถว ให้บันทึก HN สังเคราะห์, เวลา, สิ่งที่เห็นจริง และเลือก `[ ] PASS  [ ] FAIL  [ ] BLOCKED`.

## เกณฑ์หยุดบังคับทั้ง UAT

ทำเครื่องหมายและ **หยุดทั้งชุดทันที** หากพบข้อใดข้อหนึ่ง: `[ ] HTTP 500` `[ ] ข้อมูล Clinical/OPD ข้ามบทบาท` `[ ] stock ติดลบ` `[ ] ยอดบาทผิด` `[ ] Closure ไม่ถูกต้อง` `[ ] หลักฐานหายหลัง restart`.

| เหตุการณ์ | HN/เวลา/สิ่งที่เห็น | ผล |
| --- | --- | --- |
| พบ HTTP 500 | | [ ] STOP |
| ผู้ช่วยเห็น Clinical Note, diagnosis, clinical prose/hash หรือ OPD | | [ ] STOP |
| on-hand, reserved หรือ available ติดลบ | | [ ] STOP |
| ยอด Charge/Cash/waiver ไม่ตรงบาทที่กำหนด | | [ ] STOP |
| ปิด Visit โดยหลักฐาน Charge/การชำระ/waiver ไม่ถูกต้อง | | [ ] STOP |
| Allergy, Charge, Payment/waiver, Closure, stock, OPD หรือ Journey ที่บันทึกแล้วหายหลัง restart | | [ ] STOP |

หลัง STOP ห้ามทำ Scenario อื่น, retry, reset, แก้ข้อมูล หรือ restart เอง ให้เก็บฐานข้อมูล UAT ในเครื่องและส่งต่อผู้ดูแล
