# CareFlow — รุ่นแก้ไขความเสถียรสำหรับ UAT

วันที่ 20 กันยายน 2026 · สาขา `codex/uat-stability-fixes`

## ขอบเขตที่ใช้ได้

ใช้ให้ทีมคลินิกซ้อมขั้นตอนด้วยข้อมูลจำลองบนเครื่องเดียวเท่านั้น ยังไม่ใช่ระบบพร้อมใช้กับคนไข้จริง ห้ามใส่ชื่อ ประวัติการรักษา หรือข้อมูลการชำระเงินจริง และห้ามเปิดพอร์ตให้เครื่องอื่นเชื่อมต่อ

ขั้นตอนที่เปิดใช้งาน: รับผู้ป่วยจำลอง → ถามแพ้ยาแบบใช่/ไม่ใช่ → คัดกรอง → แพทย์ตรวจและลงนาม → จัดยาและตรวจปล่อย → ส่งมอบยา → คิดเงินเป็นบาท → บันทึกการชำระจำลอง → ปิด Visit → เปิด OPD Card

กรณีไม่สั่งยา ระบบข้ามการจัดยาไปคิดเงินได้ และแพทย์ยกเว้นค่าบริการเต็มจำนวนได้

## จุดที่แก้ในรุ่นนี้

1. กด Enter ขณะเลือก “ยกเลิก” จะไม่ลงนาม และกด Enter ที่ปุ่มยืนยันจะไม่ส่งคำขอซ้ำ
2. ชื่อยายังคงแสดงเมื่อแก้จำนวน/วิธีใช้ เปิดร่างที่บันทึกไว้ หรือแก้ไขคำสั่งยา
3. ยกเลิกการจัดยาแล้วเริ่มใหม่ สามารถจ่ายเงินและปิด Visit ได้ โดยไม่ลบประวัติรอบที่ยกเลิก
4. ยาหนึ่งรายการที่หยิบจากมากกว่า 20 ล็อต สามารถคิดเงินและแสดงใน OPD Card ได้ครบทุกล็อต
5. คำขอเข้าระบบด้วยรหัสเก่าที่ค้างอยู่จะไม่สร้างการเข้าใช้ใหม่หลังเปลี่ยนรหัสผ่าน
6. การลองเข้าสู่ระบบพร้อมกันถูกนับรวมในขีดจำกัดการลองรหัสผ่าน

อัปเกรดฐานข้อมูลด้วย migration `0023_uat_stability` โดยไม่แก้ไฟล์ migration เก่า ไม่ล้างข้อมูล และไม่เปลี่ยนรหัสผ่านบัญชีเดิม

## ผลตรวจของรุ่นนี้

- ชุดทดสอบหน้าจอ: 215 ผ่าน
- ชุดทดสอบระบบหลังบ้าน: 436 ผ่าน
- ทดสอบเบราว์เซอร์แยกผู้ช่วย/แพทย์: 27 ผ่าน รวมการจ่ายยา เงินสด ยกเว้นค่าบริการ ปิด Visit และเปิดระบบใหม่
- ตรวจชนิดข้อมูล ตรวจรูปแบบโค้ด และสร้างแอป: ผ่าน
- อัปเกรดฐานข้อมูลที่มีหลักฐานการเงินและ Visit ที่ปิดแล้ว: ข้อมูลเดิมอยู่ครบ และข้อห้ามแก้ไข/แทนที่ประวัติยังทำงาน
- จำลองอัปเกรดล้มเหลว: ย้อนกลับทั้งรายการได้
- ผู้รีวิวอิสระ: ไม่พบ P1/P2 สำหรับขอบเขตข้อมูลจำลอง

ยังไม่ได้รับรองการพิมพ์บนเครื่องพิมพ์จริงหรือการใช้งานจริงในคลินิก ผลนี้ไม่ใช่การอนุมัติให้ใช้กับคนไข้จริง

## เปิดชุด UAT บน Mac เครื่องนี้

ถ้าเซิร์ฟเวอร์เปิดอยู่แล้ว เข้า <http://127.0.0.1:3001> ได้เลย หากหน้าเก่ายังค้างให้โหลดหน้าใหม่

เมื่อปิดเครื่องหรือหยุดเซิร์ฟเวอร์ ให้เปิด Terminal แล้ววางสองบรรทัดนี้:

```bash
cd "/Users/ajbk/Documents/CareFlow-Rural Clinic/careflow-pilot"
CAREFLOW_DB_PATH="$PWD/data/uat/careflow-uat.sqlite" CAREFLOW_HOST=127.0.0.1 CAREFLOW_PORT=3001 CAREFLOW_COOKIE_SECURE=false npm start
```

เปิด Terminal ค้างไว้ระหว่างทดสอบ และใช้ Control+C เมื่อต้องการหยุด ห้ามเปิดเซิร์ฟเวอร์ซ้ำอีกชุด

ใช้บัญชี UAT เดิมและรหัสผ่านเดิม หากระบบขอเปลี่ยนรหัสผ่าน ให้ตั้งรหัสใหม่ที่ยาวอย่างน้อย 12 ตัวอักษร ห้ามบันทึกรหัสลงในคู่มือหรือ Git

ผู้ช่วยและแพทย์ต้องใช้คนละเบราว์เซอร์หรือคนละโปรไฟล์ การเปิดสองแท็บในโปรไฟล์เดียวกันจะใช้การเข้าสู่ระบบร่วมกัน เช่น ให้ผู้ช่วยใช้ Chrome และแพทย์ใช้ Safari

ถ้าขึ้นข้อความล็อกค้าง อย่าลบฐานข้อมูลหรือไฟล์ประกอบ ให้หยุดและตรวจตาม [คู่มือผู้ดูแล](admin-runbook.md) ก่อน

## ทดลองก่อนนำไปซ้อมกับทีม

ทำตาม [คู่มือทดสอบภาษาไทย](guide-th.md) แล้วบันทึกผลใน [checklist](checklist.md) อย่างน้อยให้ครบ:

- ผู้ช่วยถามประวัติแพ้ยาและส่งเข้าคิว แพทย์เห็นข้อมูลเดียวกัน
- แพทย์บันทึกร่างและลงนาม ผู้ช่วยจัดยา แพทย์ตรวจปล่อย ผู้ช่วยส่งมอบ
- คิดเงิน รับเงินสดจำลอง ปิด Visit และเปิด OPD Card
- กรณีไม่สั่งยาและกรณียกเว้นค่าบริการ
- หยุดและเปิดเซิร์ฟเวอร์ใหม่แล้วข้อมูลเดิมยังอยู่

การทดสอบอัตโนมัติไม่แทนการรับรองจากผู้ใช้จริงหรือการทดสอบเครื่องพิมพ์และอุปกรณ์ของคลินิก

## ก่อนใช้กับคนไข้จริง — ยังต้องทำเพิ่ม

ต้องกำหนดขอบเขตใช้งานจริงและผู้รับผิดชอบให้ชัดก่อน ได้แก่ การลงทะเบียนผู้ป่วยจริงและรายการยา/ราคาจริง การควบคุมสิทธิ์และการเข้าถึงข้อมูล ระบบสำรองและกู้คืนที่ทดสอบได้ การติดตั้งและการเชื่อมต่อที่ปลอดภัย อุปกรณ์พิมพ์/สแกน เอกสารการเงิน และแผนดำเนินงานเมื่อระบบหยุด

อย่าปิดคำเตือนหรือเปลี่ยนตัวเลือก synthetic-only เพื่อเริ่มใช้จริง ระบบส่วนที่ขาดต้องถูกออกแบบ ทดสอบ และยอมรับโดยเจ้าของคลินิกก่อน
